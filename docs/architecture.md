# Architecture

Promptly has one semantic source: `core/prompt.md`. The host model applies it; Python handles packaging and installation only. There is no deterministic string transformer, second model call, proxy, or session handoff.

```text
core/prompt.md       canonical expansion and delivery rules
adapters/*.md        native input binding and metadata templates
bundles/             generated self-contained native files
scripts/promptly.py  build, drift check, and installation
tests/               packaging and installer regression tests
evals/               optional/manual behavioral fixtures
docs/                support and usage notes
```

## Core and adapters

The build embeds the same core into each native template and records its SHA-256 digest. `build --check` verifies generated bytes and reports unexpected files under `bundles/`. Adapters contain only host metadata and request binding. A semantic change belongs in the core; a host argument or frontmatter change belongs in its adapter.

Codex, Claude Code, and OpenCode retain native adapters. Pi, Cursor, DeepSeek Harness, Grok Build, Muse Code, Gemini CLI, GitHub Copilot, and Goose use the portable generic Agent Skills bundle through installer aliases. This keeps one prompt source and avoids duplicated generated files.

## Runtime contract

1. The host loads the adapter and supplies the request, context, and attachments it exposes.
2. Promptly parses leading options and creates a concise, self-contained rewritten prompt.
3. In default mode, it prints the complete prompt under `Promptly prompt:` and then carries it out in the same conversation.
4. `--show` and `--no-run` print only the complete prompt and stop.
5. The host model saves the request and prompt to a new file in `~/.promptly/` before execution, then appends its final report in default mode. This log is the only runtime state and the only file write allowed in preview mode. See the [README](../README.md#prompt-log).

Promptly preserves host-selected models, permissions, planning modes, tools, and delegation policy. It never invokes itself recursively. It avoids unnecessary separate user-visible tasks but honors explicit user or host delegation requests. A text-only host can return the prompt but cannot execute it.

## Installer invariants

The installer renders directly from canonical sources, preflights every target before the first write, rejects linked paths, refuses differing files unless `--force` is supplied, and keeps backups beside replaced files. `--dry-run` performs the same checks without creating directories or files. Destination mappings are explicit in `scripts/promptly.py`; `DSH_HOME` is intentionally not interpreted.

## Extending Promptly

Use the generic bundle for a host that supports the Agent Skills format. Add a native adapter only when the host has a distinct, documented command or metadata contract. Add an installer alias and exact project/user destinations, then extend packaging tests. Verify discovery and preview behavior with the host's own tools; do not add a model endpoint or duplicate semantic prompt.
