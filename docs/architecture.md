# Architecture

Promptly v1 has a single semantic implementation: `core/prompt.md`. The host model applies it. Python handles packaging only, so there is no deterministic claim that a string transformer understands arbitrary requests.

```text
promptly/
  core/prompt.md             Canonical expansion and mode behavior
  adapters/*.md              Native input binding and metadata templates
  adapters/openai.yaml       Codex display metadata
  bundles/                  Generated self-contained native files
  scripts/promptly.py        Build, drift check, and installation
  scripts/evaluate.py        Blind fixture preparation and length reporting
  evals/                    Semantic cases and grading guidance
  tests/                    Packaging and installer regression tests
  docs/                     Support evidence, usage, examples, validation
```

## One core, thin adapters

The build embeds identical core text into each native template and records its SHA-256 digest. `build --check` compares every generated byte against the source. Adapters contain no task-specific expansion rules. A change to argument binding belongs in an adapter; a change to how debugging differs from research belongs in the core.

Generated repetition is intentional: users can install one file/folder without a shared path, symlink permission, network fetch, or second tool read. It avoids inconsistencies between hosts' reference expansion rules. Build artifacts are committed for manual installation; CI checks that they remain synchronized.

The core is about 1,200 words in v1. This is a fixed model-context overhead when loaded, not a per-request promise of savings. Native skill discovery usually loads only metadata until invocation. OpenCode loads the command body when it is used. Example/evaluation/documentation files are not included in any runtime bundle.

## In-conversation execution

1. The native host loads the adapter and binds the user's input.
2. The model resolves leading flags and the actual requested outcome.
3. It creates the execution specification using only exposed context.
4. It either returns that specification (`--show` / `--no-run`) or continues to the requested work in the same conversation.

This is an instruction workflow, not an interception hook or transport API. No new session is created. No model or permission settings are overridden. A planning-mode host remains limited to planning. A user request for analysis remains analysis even in default mode.

## Semantic contract

The core distinguishes provided context, supporting inferences, and discovery instructions. It preserves product choices and only fills gaps that help execution. Small reversible details go to existing conventions; only a consequential, non-discoverable missing decision blocks work.

Option parsing is described in the core and performed by the model. Its grammar is intentionally small: leading known flags, then a literal request; `--` ends parsing. Conflicts and unknown leading options stop with usage feedback. Adding future options should preserve this grammar, update fixtures, and remain independent of host-specific argument substitution.

The installer never evaluates command input. Native templates contain no shell interpolation blocks. Host-specific preprocessing may still interpret special syntax users put in their requests; that is governed by the host, not a Promptly sandbox.

## Extending Promptly

For another skill-capable agent, try the generic bundle first. For a new native command system, add a small template that binds request/context, includes `{{CORE}}` once, and declares only native metadata. Add its bundle path and installation mapping, then test actual discovery, preview non-execution, same-conversation execution, and context retention.

Do not introduce a separate LLM endpoint or hook just to emulate slash syntax. If a future host exposes a supported structured handoff API, an adapter may use it, but it must preserve mode, original constraints, available context, and authorization. That integration would need its own end-to-end tests.
